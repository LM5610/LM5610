## 👨‍💻 关于我 · About Me

你好，我是 **Regretted**。  
一名长期专注于 **Minecraft 服务端开发与运维** 的开发者，主要工作集中在：

- 插件架构设计  
- 服务端性能优化  
- 稳定性与可维护性提升  

我不太热衷宏大的叙事，更享受**把一个复杂问题拆解、解决，并稳定跑在生产环境里**的过程。  
对我来说，一段代码能长期稳定运行，本身就是最好的成就感。
